# Logic-Lab // Advanced Digital Workbench

A high-performance digital logic simulator featuring interactive schematic editing, real-time waveform analysis, and boolean algebra tools.

## Key Features
- **Node-Based Editor**: Drag-and-drop components, dynamic bezier-curve wiring.
- **Real-Time Simulation**: 60fps logic propagation with clock cycles.
- **Waveform Viewer**: Multi-track timing diagrams for signal debugging.
- **Advanced Solvers**: Karnaugh Map (K-Map) visualization and Boolean expression simplification.
- **Pro UI**: Dark-mode industrial interface with HUD elements and spatial audio feedback.

## Tech Stack
- **Canvas API**: Custom high-performance rendering for the schematic and timing diagrams.
- **GSAP**: Smooth UI transitions and modal animations.
- **WebAudio API**: Procedural sound synthesis for interaction feedback.
- **Modular JS**: Clean architecture separating logic engine from view.
